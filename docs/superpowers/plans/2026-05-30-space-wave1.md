The interface is FROZEN per spec §3 — implement exactly this so the other lanes can compile against it:

```cpp
// app/space/space_layer.h
#pragma once
#include <cstdint>
#include <functional>
namespace x3::space {
enum class Context { DeepSpace, WormholeTransit, EVA, AtmoDescent, Surface };
struct Proxy {
    enum class Kind { Planet, Ship, Station, Asteroid, Wormhole } kind;
    float pos[3]; float radius; uint32_t lodAsset; float tint[4];
};
class SpaceLayer {
public:
    void init();                          // no GPU needed for the spine itself
    Context context() const;
    void requestWormhole(uint32_t destSystemId);
    void requestDescent(uint32_t planetId);
    void requestAscent();
    void setEnvironmentVelocity(const float vel[3], const float angVel[3]);
    void environmentTransform(float out16[16]) const;
    uint32_t addProxy(const Proxy&);
    void     updateProxy(uint32_t id, const Proxy&);
    void     removeProxy(uint32_t id);
    uint32_t proxyCount() const;
    const Proxy& proxy(uint32_t i) const;
    void update(float dt);
    using TransitionFn = std::function<bool(float dt)>;
    void registerWormholeRunner(TransitionFn);
    void registerDescentRunner(TransitionFn);
};
}
```

- [ ] **Task A1 — Context state machine.** TDD: write `--test-spacelayer` asserting `context()==DeepSpace` after init; `requestWormhole(1)` → `update()` ticks → with a registered runner returning true, context advances to `DeepSpace` (arrived at dest). Implement the FSM: requests set a pending transition + invoke the registered runner each `update(dt)` until it returns true, then land in the target context (`WormholeTransit`→`DeepSpace`, `requestDescent`→`AtmoDescent`→`Surface`, `requestAscent`→`DeepSpace`). Commit.
- [ ] **Task A2 — Environment transform.** TDD: `setEnvironmentVelocity({0,0,-5},{0,0.1,0})`, call `update(1.0)`, assert `environmentTransform()` translated by (0,0,-5) and rotated by the angVel. Implement: integrate a 4×4 column-major transform from linear+angular velocity each `update`. This is the moving-environment model (spec 2.4) — ship static, environment carries motion. Commit.
- [ ] **Task A3 — Proxy registry.** TDD: `addProxy` returns a stable id; `proxyCount` increments; `updateProxy`/`removeProxy` work; `proxy(i)` round-trips. Implement a free-list-backed vector. Commit.

Interface:
```cpp
// app/space/lod.h
namespace x3::space {
struct LodSet {
    uint32_t mesh[4];        // LOD0..LOD3 mesh handles (rhi createMesh ids); 0 = unused slot
    float    switchDist[3];  // dist thresholds LOD0->1, 1->2, 2->3 (ascending)
    uint32_t levels;         // how many LODs are populated (1..4)
};
class LodSystem {
public:
    // returns the mesh handle to draw for a given camera distance
    uint32_t select(const LodSet&, float distance) const;
    // build an LodSet from a base mesh by decimation (or register pre-made chain)
    LodSet   makeFromChain(uint32_t lod0, uint32_t lod1, uint32_t lod2, uint32_t lod3,
                           float d01, float d12, float d23, uint32_t levels);
};
}
```
