## Design language from the reference
1. SILHOUETTE: angular arrow/delta with forward prongs — a shape that reads at any angle.
   (Audit our hull: if the silhouette is mush, simplify/exaggerate before detailing.)
2. HULL = VALUE RANGE, not a color: mid-grey plates + darker panel seams + lighter edge
   trim. Panel-line segmentation is the anti-blob fix. NO uniform near-black hull.
3. ENGINES ARE JEWELRY + KEY LIGHT: visible thruster pods + an exposed engine core, glowing
   cyan-blue exhaust. The ship carries its own light so it reads against space/sky/anything.
4. GREEBLE RHYTHM: density on the spine + engine pods, plainer wing planes — detail with
   rhythm, not uniform noise.
5. Plus the earlier fixes (from the w62 critique): rim/key light in the intro lighting rig,
   nav/running lights, warmer window emissive balance (not pure teal flood).
