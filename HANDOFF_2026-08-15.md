## TRAPS THAT COST REAL TIME TODAY

* **Captures write relative to CWD** — `<builddir>/bin/docs/screenshots/`, NOT the
  repo root. I read a stale repo-root PNG for an hour and concluded a working
  feature was broken.
* **Headless has no window.** `glfwSetCharCallback(nullptr,…)` is an access
  violation; it killed every capture and I bisected onto an innocent car model.
  Interactive-only testing hides it, and no test opens a window.
* **A suite can be vacuously true.** Lay-bys silently produced ZERO while every
  assertion passed, because they only checked survivors were legal — never that
  anything survived. Assert non-empty.
* **A python `.replace()` that does not match silently no-ops.** Assert after every
  scripted edit, then grep.
* **Bash `cmd //c` builds silently do nothing here.** Use the PowerShell tool with
  `vcvars64.bat`. An identical test number twice in a row means it did not rebuild.
* **Units: Tim reads FEET and MILES.** Convert at the boundary, never in the middle.
